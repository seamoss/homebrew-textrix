# Homebrew tap for Textrix

[Textrix](https://github.com/seamoss/Textrix) is an irssi-style terminal
client for Matrix, with end-to-end encryption.

```sh
brew install seamoss/textrix/textrix
```

That installs the release build for macOS (Apple silicon or Intel) or
Linux x86_64. `brew install --HEAD seamoss/textrix/textrix` builds the
latest `master` from source instead.

Textrix connects only to the servers in `~/.textrix/.env`; `brew info
textrix` shows how to make one from the example it installs.

The formula is generated by Textrix's release workflow (each release has a
`textrix.rb` attached) and copied here.
